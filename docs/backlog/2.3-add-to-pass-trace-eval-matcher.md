# Story 2.3 — Add `toPassTraceEval()` Vitest Custom Matcher

**Epic:** Deterministic Evaluation Engine

## Description

Extend Vitest's `expect` with a `toPassTraceEval()` matcher for asserting on OpenTelemetry spans.

## Tasks

- Implement `toPassTraceEval(expected, options?)` custom matcher
- Support options: `{ passThreshold?: number, warnThreshold?: number }`
- Log warning to console when score is between warn and pass thresholds

## Acceptance Criteria

- Vitest test using `expect(spans).toPassTraceEval([...])` passes and fails correctly
- Warning logged for scores between warn and pass thresholds
