# Story 4.1 — Implement Trace-to-Chronological-Story Flattener

**Epic:** Trace Distillation

## Description

Convert a potentially nested tree of OpenTelemetry spans into a plain-text chronological narrative for the LLM judge.

## Tasks

- Create `distillTrace(spans: ReadableSpan[]): string`
- Order spans by start time
- Format: `1. [toolName] called with {args} → returned {result}`

## Acceptance Criteria

- Unit test with nested spans produces correct ordered output
