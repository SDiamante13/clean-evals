# Story 2.1 — Implement `findToolCalls()` Span Inspector

**Epic:** Deterministic Evaluation Engine

## Description

Given an array of `ReadableSpan`, extract tool call names and arguments. Handle common conventions (OpenAI function-calling attribute keys, generic `tool.name` / `tool.arguments`).

## Tasks

- Create `findToolCalls(spans: ReadableSpan[])` function
- Parse tool name and arguments from span attributes
- Support OpenAI function-calling attribute keys and generic `tool.name` / `tool.arguments`

## Acceptance Criteria

- Unit test with fake spans asserts correct extraction of tool name and arguments
