# Story 6.1 — Add Pass@k Sampling

**Epic:** Pass@k Sampling

## Description

Built-in support for running an eval multiple times to ensure agent reliability.

## Tasks

- Add `samples` option to all matchers
- Run the agent function `k` times, collect scores
- Report pass if >= 1 run passes (pass@k semantics)
- Report aggregate: min, max, mean scores

## Acceptance Criteria

- Test with flaky mock agent passes at k=3 but fails at k=1
