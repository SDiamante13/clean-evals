# Story 3.3 — Implement `evaluateOutput()` with Inline Rubric

**Epic:** LLM-as-a-Judge Engine

## Description

Core LLM evaluation logic. Constructs a grading prompt from a rubric and the agent's output, then delegates to a `JudgeProvider`.

## Tasks

- Create `evaluateOutput({ output: string, rubric: string, judge: JudgeProvider })`
- Construct grading prompt embedding the rubric and output
- Return `{ pass: boolean, score: number, reasoning: string }`

## Acceptance Criteria

- Unit test with fake judge asserts pass/fail/warn thresholds
