# Story 3.1 — Define `JudgeProvider` Interface and OpenAI Provider

**Epic:** LLM-as-a-Judge Engine

## Description

Define the core `JudgeProvider` interface and implement the first concrete provider using OpenAI.

## Tasks

- Define interface: `judge(prompt: string): Promise<{ score: number, reasoning: string }>`
- Implement `OpenAIJudgeProvider` using `openai` SDK
- System prompt instructs LLM to return JSON `{ score, reasoning }`

## Acceptance Criteria

- Integration test with mocked HTTP confirms correct prompt construction and response parsing
