# Story 1.2 — Add InMemorySpanExporter Utility

**Epic:** Project Foundation

## Description

Wrap `@opentelemetry/sdk-node` and `@opentelemetry/sdk-trace-base` to provide an isolated, per-test span exporter for capturing telemetry in memory.

## Tasks

- Install `@opentelemetry/sdk-node` and `@opentelemetry/sdk-trace-base`
- Export `createTestTracer()` that returns `{ tracer, exporter, shutdown }`
- Exporter captures spans in memory, isolated per call

## Acceptance Criteria

- Unit test creates spans, reads them back from exporter
- No spans leak between separate `createTestTracer()` calls
