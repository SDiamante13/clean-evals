# Story 3.4 — Add `toPassEval()` Vitest Custom Matcher

**Epic:** LLM-as-a-Judge Engine

## Description

Extend Vitest's `expect` with a `toPassEval()` matcher for grading agent output using an LLM judge.

## Tasks

- Implement `expect(output).toPassEval({ rubric, judge, passThreshold?, warnThreshold? })`
- Print judge reasoning on failure

## Acceptance Criteria

- Vitest test using matcher with mock judge passes and fails correctly
- Reasoning is visible in test output on failure
