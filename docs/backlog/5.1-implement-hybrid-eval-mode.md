# Story 5.1 — Implement Hybrid Eval Mode

**Epic:** Hybrid Evaluation (Fail-Fast)

## Description

Combine deterministic and LLM evaluation with a fail-fast guard: if the deterministic check fails, skip the LLM call entirely.

## Tasks

- Create `evaluateHybrid({ spans, expected, output, rubric, judge })`
- Run deterministic check first; if it fails, skip LLM call and return early
- If deterministic passes, run LLM judge
- Final score = combined or LLM score (configurable)

## Acceptance Criteria

- Test confirms LLM judge is never called when deterministic check fails
