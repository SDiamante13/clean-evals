# Story 2.2 — Implement Deterministic `evaluateTrace()` Function

**Epic:** Deterministic Evaluation Engine

## Description

Core deterministic evaluation logic. Compares extracted tool calls against expected calls, returning a score between 0.0 and 1.0.

## Tasks

- Create `evaluateTrace({ spans, expected: [{ toolName, args? }] })`
- Return `{ pass: boolean, score: number, details: string[] }`
- Exact match on tool name, deep-equal on args when provided
- Score = matched / expected (0.0–1.0)

## Acceptance Criteria

- Tests for full match, partial match, no match, and args mismatch
